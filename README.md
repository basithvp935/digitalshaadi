# Wedding Template

A premium, mobile-responsive digital wedding invitation website in a burgundy and gold theme.

## Features
- **3D opening:** a premium gatefold wedding card with a gold-foil cover, satin ribbon and wax seal; tapping the seal opens the flaps in 3D and zooms into the invitation, letter-by-letter names, and an invitation card that flies in. Guests tap the wax seal to open it.
- **Music:** an original raag-style instrumental (tanpura, santoor and dholak) generated in the browser, with an on/off button.
- **Sections:** hero arch frame, verse and families, Save the Date with a live countdown, Our Story, a 3D couple photo carousel with a full-screen viewer, venue with directions, and an RSVP form that sends the reply on WhatsApp.
- Scroll reveal and 3D tilt animations, and support for reduced motion.
- A single self-contained `index.html` with all images embedded and no build step.

## Use it
Open `index.html` in a browser, or host it free on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Customise
Edit `index.html` and search for these values:

| What | Search for |
|---|---|
| Couple names | `Aadil`, `Noor` |
| Parents | `Abdul Rahman`, `Yusuf Ali` |
| Date and time | `26 December 2026`, `2026-12-26T11:00:00+05:30` |
| Venue | `Grand Pearl Convention Centre` |
| WhatsApp RSVP number | `PHONE = '919876543210'` |
| Your own song (MP3 URL) | `SONG_URL = ''` |
